# ТЗ для дизайнера — «СК» (Студенческий кабинет)

> Концепт для конкурса «Цифровой деканат будущего». Продукт вымышленный, не является официальным сервисом вуза. Все данные в макетах — вымышленные.

---

## 1. О продукте

**«СК» (Студенческий кабинет)** — личный кабинет студента, «цифровой деканат будущего». Всё, что связано с учёбой, собрано в одном месте: расписание, оценки, документы, заявки, связь с деканатом.

Ключевая идея: **забыть про бюрократию и очереди**. Нужное находится за пару касаний, интерфейс тёплый и понятный, как в хорошем потребительском сервисе, а не как в «личном кабинете портала».

Слоган-настроение: *«Учёба. Проще, чем кажется.»*

---

## 2. Аудитория и устройства

| Кто | Роль | Что делает |
|-----|------|-----------|
| Студент | основной пользователь | расписание, оценки, заявки, документы, общение с деканатом |
| Сотрудник деканата | вторичный пользователь | видит заявки всех студентов, меняет статусы, ведёт записи |

**Устройства и приоритет:**
- **Mobile-first.** Ключевой экран — телефон шириной **от 360 px**. Все сценарии работают на мобильном.
- **Десктоп (1440 px)** — полноценная адаптивная версия, не «растянутый мобильный».
- Платформа — браузер (веб-приложение).

## 3. Визуальный стиль

### 3.1 Характер
- **Тёплый и дружелюбный.** Мягкие формы, приветливый тон.
- **Чистая типографика и спокойные акценты** — как Notion / Linear.
- **Структурированные карточки, понятные статусы** — как Тинькофф / банковские приложения.
- **Плавность, «системность», мягкие тени** — как Apple / iOS.

### 3.2 Темы
- **Светлая** — по умолчанию.
- **Тёмная** — включается переключателем в настройках.
- **Все экраны отрисовываются в обеих темах.**

### 3.3 Цвет — предварительная палитра
> Финализируем после получения логотипа заказчика (палитра строится вокруг его цветов).

**Светлая тема**
- Фон: `#F7F6F4` (тёплый белый)
- Поверхность (карточки): `#FFFFFF`
- Поверхность 2: `#F0EFEC`
- Текст основной: `#1B1B1F`
- Текст вторичный: `#6F6F78`
- Границы: `#E6E4E0`
- Акцент (primary): `#5B5BD6` (индиго)
- Акцент мягкий: `#ECEBFB`
- Тёплый акцент: `#FF8A5C` (коралл)

**Тёмная тема**
- Фон: `#131316`
- Поверхность: `#1E1E22`
- Поверхность 2: `#26262B`
- Текст основной: `#F4F4F5`
- Текст вторичный: `#A1A1AA`
- Границы: `#2E2E33`
- Акцент: `#7C7CE4`
- Тёплый акцент: `#FF9A6E`

**Семантические цвета (обе темы):**
- Успех `#22C55E`, предупреждение `#F59E0B`, ошибка `#EF4444`, инфо `#3B82F6`.

### 3.4 Типографика
- **Кириллица обязательна.** Шрифты со свободной лицензией (OFL).
- Заголовки: **Onest** (геометричный, дружелюбный) или Inter.
- Текст: **Inter**.
- Иерархия:
  - H1 — 28 / 32
  - H2 — 20 / 24
  - Основной текст — 16 / 22
  - Подпись/caption — 13 / 18

### 3.5 Логотип
- Используется **логотип заказчика** (файл будет предоставлен отдельно).
- Дизайн-система и палитра выстраиваются вокруг его цветов и формы.

### 3.6 Сетка, радиусы, отступы
- Базовый шаг сетки — **4 px**.
- Радиусы: карточки **16**, кнопки **12**, чипы/бейджи **999**.
- Отступы: 16 / 20 px. Тап-зона — не менее **44×44 px**.

## 4. Структура и навигация

### 4.1 Мобильный
- **Нижняя навигация (bottom nav):**
  - **Главная** — закреплена всегда, убрать нельзя.
  - **Расписание**
  - **Профиль / Ещё**
- Остальные разделы открываются из **«Ещё»** (шторка) и с Главной.
- В **настройках** студент может закрепить дополнительные пункты в нижней навигации (до 5). Главный — всегда первый.
- **Верхняя панель:** логотип «СК», колокольчик уведомлений (с бейджем числа непрочитанных), аватар.

### 4.2 Десктоп
- Слева — боковое меню с теми же разделами.
- По центру — основной контент.
- Справа — панель уведомлений / быстрые действия.

### 4.3 Разделы кабинета
1. Главная (настраиваемый дашборд)
2. Расписание
3. Успеваемость
4. Заявки
5. Уведомления
6. ИИ «Спроси деканат»
7. Трекер дедлайнов
8. Электронная зачётка
9. Запись к сотруднику
10. Геймификация (достижения)
11. Профиль
12. Настройки

## 5. Экраны — детальные требования

### 5.1 Вход
- Логин и пароль. Кнопка «Войти».
- Пометка «Концепт для конкурса, не официальный сервис вуза».
- Состояния: ошибка неверного логина/пароля, загрузка, поле «показать пароль».
- Светлая тема (вход до авторизации — светлый, без выбора темы).

### 5.2 Главная — настраиваемый дашборд
Первый экран после входа. Набор **виджетов-карточек**, которые студент сам добавляет, скрывает и переставляет (режим «Изменить» — виджеты «трясутся»/получают крестик, как на iOS).

Доступные виджеты:
- **Расписание на сегодня** — ближайшие пары: время, дисциплина, аудитория, тип (лекция/практика).
- **Дедлайны** — ближайшие 3 задачи с датой и прогрессом.
- **Уведомления** — последние объявления/изменения.
- **Успеваемость (кратко)** — средний балл / прогресс по семестру.
- **Быстрые действия** — «Подать заявку», «Спросить деканат», «Записаться».
- **Геймификация** — уровень, баллы, ближайшее достижение.
- **Запись к сотруднику** — ближайшая запись.

Дефолтный набор (для макета): Расписание на сегодня + Дедлайны + Быстрые действия + Уведомления.

### 5.3 Расписание
- Переключатель **«Сегодня» / «Неделя»**.
- «Сегодня» — список пар: время, дисциплина, преподаватель, аудитория, тип. Текущая пара подсвечена, прошедшие — приглушены.
- **Изменения/переносы** — заметный бейдж («Перенос», «Отмена», «Замена преподавателя») + штрих.
- «Неделя» — сетка по дням, дни недели.
- Карточка пары → деталь: преподаватель, аудитория, ссылка «карта корпуса».

### 5.4 Успеваемость
- **Сводка сверху:** средний балл, число зачётов/экзаменов, прогресс «как у меня дела».
- Список дисциплин семестра. **Смешанная система оценок:**
  - где баллы (БРС, 0–100 с порогами),
  - где оценка (2–5),
  - где зачёт/незачёт.
- Вкладка **«Сессия»** — экзамены и зачёты, даты, статус (сдано/не сдано/предстоит).
- Деталь дисциплины: посещаемость, накопленные баллы, шкала, работы.
- Понятная «картина»: цветные индикаторы (всё ок / есть риски / тревожно).

### 5.5 Заявки и справки
- Список заявок со статусами.
- Типы: **Справка об обучении**, **Выписка из приказа**, **Индивидуальный график**.
- Форма новой заявки: тип, поля, кнопка «Отправить».
- Деталь заявки: статус-таймлайн (Создана → На рассмотрении → Готова / Отклонена / Требует уточнения), комментарий сотрудника.
- Статусы: «На рассмотрении», «Готова», «Отклонена», «Требует уточнения».

### 5.6 Уведомления
- Лента уведомлений, фильтр по типу: **объявление, дедлайн, изменение расписания, статус заявки**.
- Бейдж непрочитанных на колокольчике.
- Действия: «прочитать», «отметить все прочитанными».

### 5.7 ИИ «Спроси деканат»
- Чат с ассистентом. Пузыри сообщений, поле ввода.
- Над полем ввода — **чипы-подсказки** («Как получить справку?», «Когда сессия?»).
- Ответы ассистента могут содержать кнопки-действия («Открыть заявку», «Показать расписание»).

### 5.8 Трекер дедлайнов
- Список задач: название, дисциплина, дедлайн, прогресс.
- Фильтры: «Все / Активные / Просроченные / Выполненные».
- Отметка «выполнено», напоминания.

### 5.9 Электронная зачётка
- Цифровой аналог зачётки: обложка (ФИО, факультет, группа), список дисциплин с оценками.
- Визуально похоже на документ (карточка «зачётная книжка»).

### 5.10 Запись к сотруднику
- Шаг 1: выбрать тему/вопрос.
- Шаг 2: выбрать сотрудника и свободный слот (дата + время).
- Шаг 3: подтверждение записи.
- Карточка «моя запись» с возможностью отменить.

### 5.11 Геймификация
- Уровень, баллы, шкала до следующего уровня.
- Достижения-бейджи: «Первая справка», «Все дедлайны вовремя», «Сессия закрыта» и т.п.

### 5.12 Профиль
- ФИО, факультет, направление, курс, группа.
- Аватар (инициалы), электронная зачётка (ссылка), настройки.

### 5.13 Настройки
- Тема (светлая / тёмная / системная).
- Настройка нижней навигации (добавить/убрать пункты).
- Уведомления (что приходит).
- Язык, «о приложении».

### 5.14 Кабинет сотрудника деканата (отдельный)
- Вход сотрудника.
- **Список заявок всех студентов**: фильтры по статусу/типу, смена статуса, комментарий.
- **Список студентов** (поиск по группе/ФИО).
- **Записи** — слоты, на которые записались студенты.

## 6. Состояния интерфейса (обязательно для всех экранов)

Для каждого раздела отрисовать:
- **Загрузка** — скелетоны (серые плашки в форме контента).
- **Пусто** — дружелюбная заглушка с иконкой и текстом («Пока нет уведомлений», «Здесь появятся оценки»).

- **Успех** — тост/снакбар после действия («Заявка отправлена»).

## 9. Ограничения и требования

- **Только вымышленные данные** (никаких реальных ФИО, оценок, номеров зачёток).
- **Без логотипа реального вуза.** Только логотип заказчика.
- На сайте должна быть заметна пометка **«концепт для конкурса»** (на экране входа и в подвале).
- **Доступность:** достаточный контраст, тап-зона ≥ 44 px, видимый фокус, подписи к иконкам.
- **Производительность:** лёгкие ассеты, векторные иконки, системные/свободные шрифты.

## 10. Состав сдачи (deliverables)

Figma-файл, содержащий:
1. Страница **стилей/токенов** (цвета, типографика, радиусы, отступы, тени).
2. Страница **компонентов** (Auto Layout, варианты состояний).
3. **Мобильные экраны** 360×800 — светлая и тёмная темы.
4. **Десктопные экраны** 1440 px — ключевые разделы.
5. **Интерактивный прототип** основных сценариев:
   - Вход → Главная → Расписание → карточка пары.
   - Главная → Заявки → новая заявка → статус.
   - Главная → Успеваемость → деталь дисциплины.
   - Сотрудник: вход → список заявок → смена статуса.

**Handoff:** имена стилей и компонентов, экспортируемые ассеты, список шрифтов с лицензиями.
