# Деплой прототипа «СК» на сервер

Прототип работает в Docker: Next.js + встроенный SQLite (`node:sqlite`) + загруженные файлы.
База и файлы лежат в каталоге `.data`, который подключается как постоянный volume,
поэтому данные переживают перезапуск контейнера.

Схема: **браузер → Caddy (HTTPS) → приложение Next.js (порт 3000)**.

---

## Что нужно

- VPS с Ubuntu 24.04 (или Debian 12), минимум 1 vCPU / 1–2 ГБ RAM / 15 ГБ диска.
  Подойдёт любой провайдер, доступный из России без VPN (Timeweb, Beget, Selectel, Reg.ru и т. п.).
- Открытые порты **80** и **443**.
- Docker и Docker Compose (ставится одной командой, см. ниже).
- Домен **или** бесплатный `<IP>.sslip.io` (покупать домен не обязательно).

---

## Вариант 1. Деплой одной командой (если есть SSH-доступ)

На сервере (под root):

```bash
# 1. Docker + compose
curl -fsSL https://get.docker.com | sh

# 2. Код проекта (загрузите архив sk-cabinet.tar.gz на сервер, например через scp)
mkdir -p /opt/sk && tar -xzf sk-cabinet.tar.gz -C /opt/sk
cd /opt/sk

# 3. Домен (замените на свой или на <IP>.sslip.io)
cp .env.example .env
sed -i "s/^DOMAIN=.*/DOMAIN=203.0.113.10.sslip.io/" .env

# 4. Сборка и запуск
docker compose up -d --build
```

Через 1–2 минуты сайт откроется по адресу из `DOMAIN` (Caddy сам получит HTTPS-сертификат Let's Encrypt).

---

## Вариант 2. Вручную

1. Установите Docker: `curl -fsSL https://get.docker.com | sh`
2. Скопируйте проект на сервер (scp/rsync/git) в `/opt/sk`.
3. `cd /opt/sk && cp .env.example .env`
4. Откройте `.env` и укажите `DOMAIN=...`.
5. `docker compose up -d --build`
6. Проверьте: `docker compose ps` — оба сервиса (app, caddy) должны быть `running`.

---

## Бесплатный домен без покупки

Если домена нет, используйте `sslip.io`: он автоматически резолвит `<IP>.sslip.io` в ваш IP.

Пример: сервер `203.0.113.10` → `DOMAIN=203.0.113.10.sslip.io`.
Caddy выпустит на него валидный HTTPS-сертификат (порты 80/443 должны быть открыты).

---

## Полезное

```bash
docker compose logs -f app        # логи приложения
docker compose logs -f caddy      # логи HTTPS/сертификата
docker compose restart app        # перезапуск приложения
docker compose down               # остановить (данные в volume сохраняются)
```

- База и загрузки: volume `app_data` → `/app/.data` (не удаляйте его).
- Обновление кода: загрузить новые файлы → `docker compose up -d --build`.
- Node в образе: **24** (в нём доступен `node:sqlite`).
