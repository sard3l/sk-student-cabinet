# СК — Студенческий кабинет

> Концепт для конкурса **«Цифровой деканат будущего»**. Не является официальным сервисом вуза.
> Все данные вымышленные.

**Демо для жюри:** https://129.101.103.152.sslip.io

Работающий прототип (не макет): можно войти, посмотреть расписание и оценки, подать заявку и увидеть её статус.

---

## Возможности

- **Вход** по логину и паролю, сессия в httpOnly-cookie.
- **Профиль** — карточка студента (ФИО, курс, группа, факультет, направление);
  открывается по клику на имя или аватар в шапке.
- **Главная** — расписание на сегодня, новости (3 последних), успеваемость, заметки.
- **Календарь** — неделя с занятиями по времени, переключение недель, дедлайны.
- **Успеваемость** — журнал с баллами, выбор семестра и диапазона дат, посещаемость.
- **Зачётная книжка** — итоги по прошлым семестрам.
- **Документы** — заказ справок, загрузка работ (PDF/DOCX/JPG/PNG), история заявок и их статусы.
- **Учебные документы** — 6 типовых документов (учебный план, программа, график, приказы,
  положение об аттестации, правила распорядка): полный текст в приложении и **PDF** для скачивания.
- **Помощник** — чат, который отвечает **по учебным документам** (цитата из нужного раздела +
  ссылка на источник) и подсказывает по разделам кабинета; история за 7 дней.
- **Новости** — список новостей с кратким описанием и полным текстом в модальном окне.
- **Помощник** — чат с ботом-подсказчиком по разделам кабинета (история за 7 дней).
- **Достижения** — карточки наград с прогрессом.
- **Уведомления** — лента событий, отметка прочитанного.
- **Кабинет сотрудника** — раздел **«Заявки»** (справки и выписки: статусы «В работе»/«Готово»,
  загрузка готового PDF для студента) и **«Расписание»** (замена преподавателя из пула, отмена пары).
- **Староста** (для Ветровой) — отметка посещаемости 20 одногруппников и рассылка
  дедлайнов/сообщений всей группе (дедлайн попадает в календарь, сообщение — в уведомления).
- **Мобильная версия** — все основные сценарии работают на экране от **360 px** (нижняя навигация + меню-гамбургер).

## Документы и помощник

Учебные документы — единый источник данных `lib/study-docs.js`. Из него:
- строится раздел «Документы → Учёба»;
- генерируются PDF (`scripts/generate-docs.mjs` → `public/docs/`);
- помощник отвечает на вопросы (`lib/docbot.js`).

Помощник **не использует LLM и внешние API**: он ищет наиболее подходящий раздел документа
по ключевым словам и синонимам и возвращает короткую цитату со ссылкой «Открыть документ».
Если совпадения нет — срабатывают подсказки по разделам кабинета. Это бесплатно, работает
без VPN и всегда даёт проверяемый ответ со ссылкой на источник.

## Технологический стек

- **Next.js 16** (App Router, JavaScript) + **React 19**.
- **SQLite** через встроенный `node:sqlite` (без внешней СУБД).
- Аутентификация: **scrypt** + соль, httpOnly-сессии.
- Деплой: **Docker** + **Caddy** (авто-HTTPS).
- Шрифт **Inter**, иконки — Material Symbols.

> SQLite выбран для прототипа (простота и нулевая настройка). Для продакшн-нагрузки
> слой данных изолирован в `lib/db.js`, чтобы заменить БД на PostgreSQL без переписывания страниц.

## Запуск локально

Требуется **Node.js 24+** (в нём доступен `node:sqlite` без флагов).

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

База создаётся автоматически при первом запуске и заполняется вымышленными данными:

- `.data/app.db` — SQLite-база;
- `.data/uploads/` — загруженные файлы.

При изменении схемы/сидов удалите `.data/app.db` и перезапустите сервер.

### Скрипты

```bash
npm run dev      # разработка (Turbopack)
npm run build    # production-сборка
npm run start    # запуск production-сборки
```

## Мобильная версия

- Брейкпоинты: `≤900px` (планшеты) и `≤600px` (телефоны от 360px).
- Нижняя навигация с быстрыми разделами + выдвижное меню со всеми пунктами.
- Таблицы (журнал, история загрузок) прокручиваются по горизонтали внутри своих блоков.
- Чат помощника подстраивается под высоту экрана, поле ввода не перекрывается навигацией.

## Безопасность

- Пароли хранятся только в виде **scrypt-хэша с солью**, сравнение — `timingSafeEqual`.
- Сессия — случайный 32-байтный токен в **httpOnly** cookie (`sameSite=lax`, `secure` в проде).
  В базе хранится только **SHA-256 хэш токена** — при утечке БД сессии не переиспользовать.
- **Rate limiting** на вход: не более 30 попыток за 5 минут с одного IP.
- **CSRF-защита**: проверка `Origin` на всех изменяющих запросах + `SameSite=lax`.
- **Security-заголовки**: `Content-Security-Policy`, `Strict-Transport-Security`,
  `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`.
- Все данные и API **скоупятся по `user.id`**: студент не может открыть чужие оценки,
  заявки или заметки; смена статуса заявки доступна только сотруднику.
- Лимиты длины полей и ранний отказ по размеру загрузки (защита от «тяжёлых» запросов).
- Загруженные файлы лежат вне `public/` и не отдаются по прямой ссылке.
- В коде нет ключей и паролей сервисов; `.env`, `.data`, `*.db` исключены из репозитория.
- На сервере: **fail2ban** (защита SSH от перебора), автообновления безопасности,
  **ежедневный бэкап** SQLite-базы (хранится 14 дней).
- Демо-пароли в интерфейсе и сидах — это **тестовые аккаунты** для жюри, а не секреты.
